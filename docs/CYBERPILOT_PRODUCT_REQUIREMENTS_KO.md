# CyberPilot 제품 요구사항 — 설치와 모바일 실시간 상태 조회

기록일: 2026-11-13 (Asia/Seoul).
이 문서는 사용자가 명시한 제품 요구와 작성자의 제안을 구분한다.
전체 제품 요구사항·완료 일정·완성률은 아직 확정되지 않았다.

## 사용자가 명시한 요구

### INSTALL-01 — 콤마에서 주소 입력으로 설치

당근브랜치를 설치하듯, 지원하는 콤마에서 설치 주소를 입력해 CyberPilot을
설치하고 정상 실행하는 배포 경험을 제공한다. 정확한 설치 URL과 지원 기종·차량을
안내하고, 실제 오픈파일럿 연동·필요한 모델/설정·시작/업데이트 경로를 검증한다.

현재 상태: CyberPilot 배포판의 설치·장치 검증 미완료.
기존 upstream 설치 안내나 오프라인 wheel 설치 성공을 이 요구의 완료로 세지 않는다.

### MOBILE-01 — 모바일 웹에서 실시간 상태 확인

웹당근과 유사한 사용 경험으로, 휴대폰 브라우저에서 CyberPilot/콤마 상태를
실시간 확인할 수 있게 한다. 모바일 화면에서 읽고 사용할 수 있어야 하며,
실제 상태 데이터의 수신·갱신·연결 끊김을 확인할 수 있어야 한다.

사용자가 명시한 것은 모바일 웹의 실시간 상태 조회다. 웹당근의 전체 기능 목록,
화면 구성이나 현재 저장소의 특정 웹 구현을 그대로 채택했다고 해석하지 않는다.

현재 상태: 인증된 읽기 전용 대시보드·호스트 실시간 수집·기본 꺼짐 Cereal 수신기를
구현했다. 클라우드의 실제 호스트 HTTP·모바일/PC 브라우저·연결 끊김과 합성 topic
검증은 제공하며, 실제 콤마 메시지/휴대폰 통합 검증은 아직 필요하다.
사용법과 현재 범위는 [모바일 웹 안내](CYBERPILOT_WEB_KO.md)를 참조한다.
기존 오프라인 HTML/Markdown 리포트와 합성 예제는 이 요구의 완료 증거가 아니다.

## 기본 표시 항목 제안 — 사용자 확정 항목과 구분

작성자의 초기 제안이며 실제 신호 가용성 점검과 화면 설계에서 구체화한다.

- 장치 연결 상태와 마지막 수신 시각, 갱신 지연·연결 끊김 표시.
- 실행 중인 브랜치·버전·커밋, 서비스 실행 상태.
- 차량 연결과 시스템 준비 상태, 현재 확인할 수 있는 경고·오류.
- CyberPilot 기능 상태와 진단 정보. 각 값의 의미·단위·출처가 확인된 항목부터 제공.

실제 값, 합성 데모, 미수신·미확정 값을 화면에서 구분한다. 값이 오래되거나
연결이 끊겼을 때 이전 값을 현재 상태처럼 표시하지 않는다.

## 구현 전에 정할 사항

- 접속 범위: 같은 네트워크에서의 접속과 외부망 접속의 지원 범위.
- 장치/사용자 인증, 접근 권한과 연결 방법.
- 표시할 실제 신호와 출처, 갱신 주기·지연·오래된 데이터의 판정 기준.
- 지원 콤마 기종·차량·브랜치와 UI의 연결/재연결 동작.

현재 구현은 loopback 기본, LAN 명시적 bind, 비공개 bearer 토큰, 선택적 TLS,
1초 polling/5초 topic별 freshness를 사용한다. 외부망 자동 접속과 실제 지원
기종·차량은 콤마4 / 더 뉴 싼타페 TM 2021년식 디젤로 지정됐으며 실제 연동은 미검증이다. 모바일 상태 조회 요구 자체를 보류하는 사유로 삼지 않고,
제품 설계와 실제 연동 작업에서 해결한다. 실제 차량 데이터·환경 검증은 기존
허용 범위와 별도로 관리한다.

## 완료 확인

INSTALL-01은 지원 대상으로 지정한 장치에서 실제 설치·정상 시작·업데이트 및
복구 절차를 검증한 결과가 필요하다.

MOBILE-01은 지원 모바일 브라우저에서 실제 상태를 받아 갱신하는 통합 검증이
필요하다. 화면 가독성과 연결 끊김·재연결·오래된 값의 표시도 확인한다.
합성 데모의 화면 검증과 실제 장치의 실시간 연동 검증 결과는 각각 기록한다.

설치 성공, 웹 접속 성공, 상태 수신 성공, 주행 기능 검증을 구분해 보고한다.
R_BUDGET·Static Evidence Gate·실제 신호/설정/시각 결속 등 기존 미해결 항목은
별도로 유지하며, 이 요구사항 기록이 실차 활성화 승인을 발행하지 않는다.
