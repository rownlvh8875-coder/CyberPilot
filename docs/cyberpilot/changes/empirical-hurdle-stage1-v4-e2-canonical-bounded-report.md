The old readiness provider retained64 TRAIN/DEV feature matrices, pipeline snapshots,32 caches and eager horizon paths. The new exact-type `BoundedSyntheticProvider` owns source-block snapshots and ordered index vectors, small models and TRAIN saved vectors. It materializes one job feature matrix with512-row assembly workspace, verifies its source binding, and rejects retained ndarray aliases when the lease closes. Same logical source identity must have one owner; shared physical TRAIN/DEV source bytes do not unlock the DEV role. Source immutable snapshots are bytes-backed, carry content hashes and owner stamps, and detect surviving original caller/view mutation. Release also checks the ultimate ndarray owner and raw immutable bytes owner; a CPython-only reference-count registry distinguishes retained bytes aliases from borrowed owners already counted by another active lease. Pointer identity is secondary ephemeral mutation protection, not cryptographic authentication of a private file.
