**Goal:** Automatically run the full cloud suite/static checks with a shared local verifier and credential-free read-only GitHub workflow.

**Architecture:** Small stdlib verification runner reuses cloud helpers. Thin separate workflow installs locked app/SDK environments, invokes the runner, uploads logs even on failure. Existing app700 workflow and math remain unchanged.

**Tech Stack:** Python3.12.13/uv0.12.23, existing DEV pins and HF SDK2.4.0 hash lock, unittest/PyYAML, existing pinned Actions.

- New external output only; existing/symlink/source-root outputs cannot be overwritten.
- No HF credentials/API/live backup invocation in CI; HF_HUB_OFFLINE=1 in verifier children.
- App/SDK separate, SDK2.4.0 and Python3.12.13; app lock/API/math/workflow unchanged.
- At least70 actual unittest cases, dynamic new total, no skips/failures/truncation/duplicate ledger.
- Closed GATES retained; synthetic unit work NONZERO/unaggregated; no physical activation.
- Deliver reviewed feature PR only. Main merge/HF backup refresh excluded this stage.

## Review Focus

- Truncated/forged/multiple or unexpectedly tiny test runs must not become success.
- Missing SDK/dependencies/executable must preserve a bounded error without success artifacts.
- Output collisions/symlink paths and source mutation must not overwrite or falsely qualify.
- CI must use pinned interpreters/actions and no HF secrets/write token permissions.
- Artifact failure logs must remain available; absent/skipped checks are not PASS.
