- Shared `_preflight`, R44/R46 implementations, cloud tools and CI unchanged.

- CompareError inherits ValueError: classified codes must be re-raised before generic translation.
- Real NUL/permission failures must reject before source/input reads or output creation.
- CLI diagnostics must not expose private path or injected exception text.
- TypeError/interrupts and later-stage defects must not be relabeled as preflight IO.
- R34 helper reuse by R44/R46 must not acquire a broader exception contract.
