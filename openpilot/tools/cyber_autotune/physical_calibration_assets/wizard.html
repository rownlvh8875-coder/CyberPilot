A. 실제 device / sensor 확인

확인되지 않으면 UNKNOWN / PENDING 그대로 두세요. 해상도만으로 센서를 추정하지 마세요.



B. Optical center 높이와 mount 위치


height: 관측한 ground plane에서 camera optical center까지의 수직 거리. Lens housing 끝이나 windshield edge 높이가 아닙니다.



datum은 independently surveyed vehicle datum입니다. 실제 원점과 optical center를 문서/사진으로 기록하세요. X/Y 0을 임의로 넣지 마세요.



Height의 기존 uncertainty/method/instrument 입력은 지웁니다. 다른 입력은 유지합니다.
높이 관측만으로 full calibration admission이나 pixel→meter 계산이 허용되지 않습니다.


C. 각도와 독립 reference


Rz(yaw) Ry(pitch) Rx(roll), 내부 radians. +yaw: X 전방 → Y 왼쪽; +pitch: X 전방 → 아래; +roll: Y 왼쪽 → Z 위. 관측 reference와 동일 convention이어야 합니다.


TIER A: independently surveyed stationary target / checkerboard / AprilTag.
TIER B: independent inclinometer/digital level + surveyed reference.
TIER C: phone IMU/informal — 독립 admission 불가.




D. Stationary target / survey method


차량 정지, 안전한 평탄한 장소, 실제 instrument/target/reference를 준비하세요.
SURVEYED_CHECKERBOARD / SURVEYED_APRILTAG / SURVEYED_STATIONARY_TARGET은 target의 실제 width/height/distance,
vehicle datum까지 geometry, ground survey, 독립 uncertainty 자료가 필요합니다. OPTICAL_CENTER_SURVEY는 optical center 위치와 축을 independently survey한 기록을 요구합니다.


이 wizard는 사진에서 pose를 solve하거나 calibration fit을 수행하지 않습니다. 측정·fit/holdout 결과를 따로 확보하고 입력하세요.

Local printable checkerboard / 측정 sheet

100% / actual size 출력 후 ruler/caliper로 실제 크기를 재측정. Nominal print dimensions는 physical truth가 아닙니다.


E. Ground / distortion evidence


“평평해 보임” ≠ 0° slope truth. Ground survey method, observed slope bound, evidence와 vertical approximation bound가 필요합니다.
ground_vertical_m value=0은 surveyed datum 정의이며 bound는 별도입니다.


Distortion은 UNKNOWN / PENDING 기본입니다. 실제 independently bounded undistorted residual evidence가 있을 때만 선택하세요.
distortion_residual_px value=0은 residual 중심 정의이며 zero distortion coefficients를 의미하지 않습니다.


F. STATIC_SOURCE_INTRINSICS ≠ INDEPENDENTLY_MEASURED_INTRINSICS


실제 device identity / hardware evidence를 입력한 뒤 pinned source를 확인하세요.
Nominal focal/principal point는 측정값이 아니며 per-unit uncertainty와 distortion을 대신하지 않습니다.






G. 명시적으로 선택한 local 측정 증거


Stationary measurement 사진/target photo/기록/instrument/독립 metrology 문서만 선택하세요.
Private comma4 route frames/raw logs는 열지 마세요. 파일 이름·경로는 전송하지 않으며 binary는 local/private workspace에만 저장합니다.




Uncertainty는 사용자가 conservative absolute bound를 기록합니다.
줄자 눈금 1 mm가 전체 설치 uncertainty 1 mm를 의미하지 않습니다. instrument resolution과 total bound를 분리하세요.
METROLOGY_REVIEW 선택은 독립 검토 증거의 선언이며 wizard가 검증을 수행했다는 뜻이 아닙니다.


H. Draft / preflight / immutable receipt


값·unit·bound·method·source·evidence hash를 확인하세요. 누락된 ground/distortion/uncertainty는 admission을 막습니다.






CALIBRATION_EVIDENCE_ADMITTED 이후에도 INDEPENDENT_CALIBRATION_VALIDATION_PENDING입니다.
기존 admitted 값은 덮어쓸 수 없습니다. 재측정은 새 local session/version입니다.
