# R32.1 — 허용된 로컬 환경의 화면 확인 인계

클라우드 Chromium은 about:blank에 정상 응답했으나 리포트 file:// 탐색에서
`net::ERR_BLOCKED_BY_ADMINISTRATOR`를 반환했습니다. 정책은 변경하거나
우회하지 않았으며, 실제 리포트 화면 검증은 아직 완료되지 않았습니다.

이 문서는 화면 확인만을 위한 절차입니다. 코드 설치·모델/F61 실행·로그 해독·
Controller/Runtime/CAN·실차 연결·r/dt 계산·차량 활성화는 하지 않습니다.

1. R32.1 근거 ZIP을 노트북의 별도 폴더에 풉니다. 또는 이미 생성한 정상 R32
   결과 폴더를 사용합니다. 원본 결과를 편집하지 않습니다.
2. `report-local-sign-1/index.html`과 `report-local-resumed-1/index.html`을
   파일 열기가 허용된 로컬 브라우저에서 엽니다. 서버나 의존성 설치는 필요 없습니다.
   관리 정책으로 차단되면 중단하고 정책 담당자에게 확인합니다. 보안 옵션을
   끄거나 다른 전송 방식으로 차단을 우회하지 않습니다.
3. sign: 정규화/정수 그래프2개, 기록4개 행, final `[2,-2,0,2]`, 한글 표시,
   가로·세로 스크롤을 확인합니다. 이전 requested/applied가 별도 열인지 확인합니다.
4. resumed: 기록1행/index5, counter89→90, final-2/steer_request=false,
   단일 샘플 점이 보이는지 확인합니다. 요청 비트 해제는 command0을 뜻하지 않습니다.
5. 넓은 창과 좁은 창에서 글자가 잘리거나 겹치지 않는지 확인합니다. 그래프
   좌표는 표시용 반올림이며 정수/hex 표 값이 기록의 기준입니다.

확인한 OS·브라우저 버전·파일 이름과 PASS/FAIL 항목을 기록합니다. 공유할 경우
문서 부분만 캡처하고 개인 탭·주소·계정 정보는 제외합니다. 미확인 항목을 PASS로
적지 않습니다. 노트북 관찰 결과는 별도 로컬 선언이며 자동 인증 자료가 아닙니다.

화면 확인이 끝나도 R_BUDGET=UNRESOLVED, Static Gate=FAIL, 실제 r/T2/scale=null,
F70UH/V/F71·실차 활성화 금지는 바뀌지 않습니다. 접근성 전체 감사나 브라우저
호환성 matrix, 실제 차량·물리 안전·성능 자격으로 승격하지 않습니다.
