## Extractor and state boundary

integration_tools/message_boundary_types.py defines seven exact frozen/slots
carriers. message_boundary.py implements
extract_synthetic_message(frame:SyntheticBoundaryFrameV1)->PreparedLateralInputV1.
There is no file/log/dictionary/native-object reader or automatic initialization.
All fields/metadata must be explicitly supplied, including zero/False values.

Exact root/nested classes precede every nested access. Builtin metadata, profile,
sequence, index/declared adjacency, numeric domain and cross-field custody checks
follow the preregistered order. Foreign/subclass/property objects cannot become
valid inputs via duck typing, conversions or default fallback. Missing constructor
args/unknown kwargs are TypeError; bad supplied records raise MessageBoundaryError
with stable .code, not a partial prepared result.

Output only copies public LateralInput and the supplied immutable LateralState:
no step, simulate, quantization, output command, next state, writeback, r/dt or F61
input API. Floats retain exact bits/sign, including negative zero. Binary64 values
are not silently converted to Float32. Domain/scale bounds are unchanged.

Custody means declared consistency, NOT proof of an actual prior transition.
The source previous-applied/counter values must equal the declared model state,
but another valid prior integer candidate15 rather than16 is preserved with
SYNTHETIC_DECLARATION_ONLY. No native field supplies that model bookkeeping.
An index1 state with applied100/current scale5 is preserved, not clamped/rescaled.
The extractor never computes95 or19.0 for it.

B09 checks inconsistent declared adjacency, not global replay prevention. Same
original immutable frame retry is deterministic, and independent callers do not
share mutable state. No ownership, history-certification or persistence protocol.
R12's distinct fixed-registry/trusted-prefix validation is unchanged, not weakened.
