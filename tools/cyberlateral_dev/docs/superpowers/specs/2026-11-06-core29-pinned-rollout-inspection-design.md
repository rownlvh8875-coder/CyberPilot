Builder-selected offline increment under the user's standing delegation; no new approval gate.
This is historical fixed-fixture byte identity, not generic saved-input validation or recomputation.

## Contract

`inspect_rollout_case(case_id: object, input_root: Path) -> dict` accepts only exact built-in
strings sign-cycle, declared-difference, late-invalid. Reject other cases before touching paths.
Pin each case's three CORE28 files (INPUT.json, RESULTS.json, SHA256SUMS.txt) by exact
size and full SHA256 from the verified CORE28 seal. Keep pins local; runtime need not open
the old ZIP. Do not parse caller JSON or trust its status, checksum, schema, or metadata.

Open an exact-three-regular-file non-symlink directory using unchanged CORE18 bounded
descriptor readers. Capture each member once, bounded by its pinned size; reject mismatch.
Check final root path/device/inode and post-capture layout. This is captured byte identity,
not an atomic filesystem snapshot, continuous protection, or path-ancestor authentication.
No writes, retries, repair, extraction, model/reference/quantizer/F61 execution.

Return canonicalizable receipt: inspection status PINNED_CORE28_ARTIFACTS_MATCH/exit0;
separate historical result MATCH/0/3 steps, DIFFERENT/1/3, REJECTED/2/0; captured file
identities, pinned provenance, zero new execution counters, false semantic/recomputation/
source/vehicle authority flags, unchanged gates. Runtime ZIP verification is explicitly false.
No paths/times in receipt. Reformatting or new catalog bytes reject even if semantically equal.

CLI `tools/core_rollout_inspect.py --case CASE --input-root DIR`: no --run, output,
arbitrary JSON, rate, or policy options. Reject duplicates, abbreviations and empty values
before project imports/path access. All three valid historical cases inspect with exit0.
Known errors preserve fixed code; all operational/usage/output failures exit2, no success.
Complete short descriptor writes; failed help/stderr/output cannot appear successful.
Guard sys.path and sys.dont_write_bytecode through parser/output and restore on all exits.
Use caller `-I -B` for cold interpreter imports. Parent shell redirection is outside API custody.
